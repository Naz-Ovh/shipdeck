# Rust Coding Rules - Mandatory for Agents
Correctness, range integrity, and cross-platform behavior outrank performance. Apply optimization rules to network, disk, parser, and scheduling hot paths—not cold setup, UI, or error paths. Dependency approval still applies.
- **Ownership**: Never add `.clone()`, `.to_owned()`, `Arc`, or `Mutex` just to satisfy the compiler. Fix ownership; prefer `&[T]`, `&str`, `Cow`, or caller buffers. Reuse buffers with `.clear()` and use `with_capacity` when sizes are known. Justify unavoidable hot-loop allocations.
- **Dispatch/layout**: Avoid `Box<dyn Trait>`/`Box<dyn Error>` in hot paths; prefer generics or enums where useful. Choose AoS/SoA by access pattern. Use `#[repr(C)]` for FFI/ABI, never padding or performance; `#[repr(transparent)]` only for eligible wrappers.
- **`unsafe`**: Never use it to avoid clones/checks or for unmeasured speed. Isolate it behind safe APIs. Every block needs a `// SAFETY:` comment proving pointer, alignment, initialization, bounds, lifetime, and aliasing invariants. Run Miri where supported; otherwise add platform tests. Never claim unrun checks passed.
- **Concurrency**: Do not default to lock-free or thread-per-core. Prefer bounded channels or short-held locks. Never hold locks across `.await` or blocking I/O. Atomics require documented ordering and correctness; lock-free requires measured contention.
- **I/O**: Reuse borrowed slices and buffers only when range and lifetime correctness are preserved. No `mmap`, `io_uring`, or new crates without approval; keep OS code behind `cfg` with fallbacks. Validate length, alignment, and endianness before byte casts.
- **Panics/errors**: No production `.unwrap()`, `.expect()`, or unchecked indexing unless provably infallible. Use checked arithmetic and `TryFrom` for untrusted sizes, offsets, and ranges; no truncating `as` casts. Wrapping/saturating arithmetic must be intended, never hide bugs. Never discard errors with `.ok()`, `.unwrap_or_default()`, or `let _ =` in download, range, or filesystem code. Preserve concrete error sources; errors need not be `Copy`.
- **Verification**: Define types/signatures first for non-trivial modules. Run formatting, relevant tests, and `cargo clippy --all-targets -- -D warnings -W clippy::pedantic -W clippy::perf`. No broad `#[allow]`, deleted tests, or weakened assertions. Never claim unrun checks or unmeasured performance gains.
- **Files**: Split by responsibility. Target 300–550 LOC where natural; small modules are allowed. Hard caps: 800/file, 100/function. `lib.rs`/`mod.rs`:  declarations/re-exports only. Move tests to `_tests.rs` sibling file.
