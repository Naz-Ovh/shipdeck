# Releases: ids, layout, exit codes, the release workflow

What servers already depend on, and what the scripts that call shipdeck
already depend on. Both are contracts: add, never renumber or move.

## On the server

- Release ids and the `current`/`releases`/`backups`/`shared` layout are a
  contract with servers already deployed to. Change them only on purpose.

## For scripts

- The exit codes in `shipdeck_headless::exit_code` are a contract with the
  scripts that call shipdeck. Add new ones; never renumber.

## The release workflow

- `.github/workflows/release.yml` is generated by dist from
  `dist-workspace.toml`. Change the toml and run `dist generate`; never edit
  the yml by hand.
