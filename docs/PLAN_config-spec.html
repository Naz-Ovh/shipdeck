deploy.yaml, step by step

Every step, in order. run commands start after shipdeck finishes the step; check commands must pass.
  • Steps live under pipeline:.
  • pack.files has include and exclude, each split into project and deploy.
  • When a release fails after the restart, shipdeck asks before rolling back and rolls back by itself after 30 s. rollback: ask is the default.
  • A manual rollback runs done too, with SHIPDECK_ACTION=rollback.
  • Errors are printed in colour, and deploy.schema.json gives editors completion.
